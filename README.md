
### 板块涨停分布 · 维度与题材来源

- **两个维度**：`细分题材`（默认）/ `一级行业`，可一键切换；两者共用同一张表格与排序状态。
- **工具**：板块/个股搜索、`≥2家` 过滤（默认开）、全部展开、显示其余板块（默认前 20）。
- **细分题材来源**：`theme_board.py` 用东财概念板块成分股建「个股 → 多题材」反向索引，过滤「连续亏损/最近多板」等伪概念，近义概念按 `ZT_THEME_ALIASES` 合并（光模块·CPO / 商业航天 / 光伏新技术…），并自动发现「X字辈」炒作（白名单限生肖/祥瑞字，防噪音）。
- **口径诚实**：题材级无权威资金流字段，表头「涨速\*/净额亿\*」按成分股主行业近似；一级行业维度给的是腾讯板块榜原始净流入/涨速，名称对不上时标 `~`。
- 首板雷达 / 短线精灵为**语音播报**（Web Speech API），无弹窗。

### 板块强度榜 · 开盘啦式排版（2026-11-06）

「涨停与风险」页按开盘啦「板块 · 历史统计」的排版方式重构，原来一板块一张卡片改成**密集可排序表格**。

- **市场情绪计数条**（顶部一行）：涨停 / 炸板 / 跌停 / 最高连板 / 炸板率 / 昨涨停晋级 / 昨涨停今均涨。
  开盘啦的「市场情绪」是 tab 即数量对比，这里做成等宽数字条，一屏看完全部情绪指标。
- **板块强度榜表格列**：`#`（强度名次，不随排序改变）· 板块 · 强度 · 涨停（红方块）· 梯队 · 涨幅 · 涨速 · 净额亿 · 领涨。
- **排序即筛选**：点列头切换升降序（默认强度↓）。缺值恒沉底，不会因为升降序翻转跑到最前。
- **标记体系**：🔥 持续火爆（连续两档强度 ≥6000，或 ≥3 家涨停且最高 ≥3 板）· ▲n 名次上升 / ▼n 下降（对上一档 5 分钟）· 红方块涨停家数 · `~` 行情为近似映射。
- **二级下钻**：点行展开成分股（股票 / 连板 / 涨幅 / 封板资金 / 额 / 首封 / 所属行业），前 3 个自动展开。
- **连板天梯 · 晋级率**：`5板 2只 … 晋级 100%`，按「昨 N 板 → 今 N+1 板」分层算，1 板标「新首板」。

#### 强度是本地口径，不是开盘啦官方值

开盘啦强度是私有算法，无公开文档，外部无法复刻。本工作台用**公开字段加权绝对刻度**：

```
强度 = 10000 × Σ(wᵢ×xᵢ) / Σwᵢ
涨停家数 34% · 最高连板 20% · 涨幅 18% · 涨速 12% · 净额 16%
x 均为绝对刻度（count/8、lb/5、(zdf+2)/11、(speed+1)/4、(nf+8)/33），非当日 min-max
```

- 用绝对刻度是为了**可跨时点比较**：min-max 每天都有满分板块，「持续火爆」就失去意义。
- **缺失维度剔除后重归一，不补 0**。补 0 会冤枉「资金字段没匹配上」的板块 —— 与 2026-10-21「炸板率恒 100%」是同一类坑（缺失 ≠ 最差）。
- UI 上固定标「本地口径」，鼠标悬浮给完整公式。

#### 名次变化依赖历史落盘

`zt_board_stat.py` 把每档（5 分钟一个 bucket）strength 写进 `data/zt_strength_history.jsonl`（只记当日、同档去重、超 600 行裁到 400）。

- 首档没有历史 → `rank_delta = None`，前端**不显示箭头**，不编造「上升 3 名」。
- 该文件同时是多日区间强度 / 过滤「一日游」题材的基础。

#### 晋级率 / 亏钱效应

- **昨涨停晋级率** = 今日再涨停 ÷ 昨日涨停总数（基线来自 `data/prev_zt.json`，82 只）。
- **分层晋级**：昨 1 板 61 只 → 今日 2 板 4 只 = 6.6%；昨 2 板 17 只 → 3 板 3 只 = 17.6%。
  基线里只有 codes 没有分层明细（老缓存）时，标 `prev_ladder_known=False`，前端显示「晋级 --」，**不拿总口径冒充分层**。
- **亏钱效应** = 昨日涨停股今日平均涨跌幅 + 下跌占比（全 A 帧现算）；取不到全 A 帧则为 `None`。
- **炸板率** = 炸板 ÷ (涨停 + 炸板)；分母为 0 返回 `None`，不返回 0 假装「无炸板」。

#### 行情近似映射要标 `~`

腾讯行业榜实测可用 151 条（行业 + 概念），东财一级行业名与之**不一一对应**（如「光伏设备」腾讯榜无此项 → 落到别名「电力设备」）。

- 因此「光伏设备」和「电力」两行会出现完全相同的涨幅/涨速/净额 —— 这是近似映射导致的，不是数据错乱。
- 后端在分组里带 `board_match`（`exact` / `fuzzy` / `alias`）+ `board_name`，前端对非 `exact` 的行标 `~`，悬浮说明取自哪个腾讯板块。
- **领涨列取本板块涨停池里最强的那只**（连板高优先），不取腾讯板块榜领涨股 —— 后者在近似映射下会出现「电力」行挂光伏股，属于张冠李戴。

### 首板推票 v2 · 三层漏斗（2026-11-06 起）

用户拍板原则：**打首板之前只推「当天第一次涨停 + 即将涨停 + 封板意愿特别强」**。
v1 的「+3~4% 早段异动」已彻底移除（实盘反馈：推过 4 次，买了就跌）。

| 层 | 做什么 | 接口 | 语音 |
| --- | --- | --- | --- |
| L0 趋势题材 | 涨停家数 / 连板梯队 / 题材涨幅 / 涨速 / 主行业资金 / 新闻催化加权 → 趋势题材榜 | `/api/theme_pick` | 否 |
| L1 低位挖掘 | 只在趋势题材成分股里找未涨停、题材内相对低位、量能刚抬头的票 | `/api/theme_pick` | 否 |
| L2 临板首板 | 板进度 ≥0.85 + 真实五档封板意愿 ≥68 + 趋势质量 ≥55 + 连续 2 帧确认 | `/api/sprite` | **是，唯一强播报** |

- **板进度** = `(现价-昨收)/(涨停价-昨收)`，自动适配主板 10% / 创业科创 20% / 北交 30% / ST 5%。
- **封板意愿**只用腾讯 `qt.gtimg.cn` 真实五档字段（委差、卖一量、买五档、外盘、均价、新高、60s 涨速），取不到就降权并标注，**不编指标**。
- 排除项：今日已封板 / 当前涨停池 / 昨日涨停（连板接力）/ ST / 退市 / N·C 新股 / 巨量出货；冷却 300s、每帧最多 3 只、大盘情绪闸门沿用。
- 新闻催化：`news_catalyst.py` 走东财全球财经快讯（近 4h / 200 条），只做真实催化加分与标签，源不可用标 degraded，**绝不编造传闻**。
- **会话态六分**：`preopen / auction / trading / lunch / paused / closed` 由交易时钟 + 实时帧共同判定。只有 `trading` 才允许标「即将冒头」，杜绝把盘前或躺平票包装成爆发信号。
- **盘前隔夜榜**：当日涨停池为空时，用「昨日涨停成分股所属题材 + 真实快讯」给方向榜，前端明确标「隔夜口径 · 昨涨停」，开盘产生涨停后自动切回实时 L0。
- 回归测试：`tests/test_first_board_v2.py` 锁死「+3~4% 早段 0 事件」「弱意愿不推」「连板接力排除」；全量 `unittest` 23 项。

### 国家队 ETF · GJD 资金面（2026-11-06，ADR-0049）

「市场全景 → 国家队ETF」。回答一个别处看不到的问题：**长钱今天是在托底还是在派发**。

- **池子**：`core` 20 只 + `watch` 4 只宽基 ETF（沪深300 / 中证500·1000 / 创业板 / 科创50 / 上证50 等）。
- **两个指标必须一起看**：
  - **放量倍数** = 今日成交额 ÷「20 日均额 × 该 ETF 当日同时点的成交额分布曲线」。
    用各自曲线而不是笼统按时间摊，否则「大票成交晚」会被误判成缩量。
  - **主动净买入** = `(外盘 − 内盘) × 100 × 成交均价`（亿元），成交均价 = 成交额 ÷ (成交量×100)。
- **分档**：强力买入 ≥2.0× 且净买入>0 / 明显买入 ≥1.5× 且净买入>0 / 温和放量 ≥1.2× / 常态 0.8~1.2× / 缩量 <0.8×。
- **`放量出货`（≥1.2× 但主动净卖出）**：这是本模块相对第三方跟踪器**额外**做的一档，也是最有价值的一档 ——
  只看「放量」会把高位派发误读成增持。
- **接进推票的方式**：GJD 是**池级**信号，只能改闸门（见 ADR-0049）：
  `position_cap_pct` 的 pp 修正 + `max_picks` 的只数修正；**不做个股排序加分**
  （对池内每只票同加一个常数，排序结果不变 = 假改造）。
- **诚实标注**：基准交易日（20 日均额截止日，通常比今日早 1~2 天）直接写在页面上；
  缺内外盘时净买入显示 `--` 而不是 `0`；缺曲线时标「线性降级」。
- **数据自建**：基准每日从第三方快照取一次并落 `data/gjd_etf_base.json`（缓存，不入库），
  实时走腾讯行情（与全 A 同源，零新依赖）。第三方站点挂了只影响基准新鲜度，不影响实时值。
