# market-monitor · 多市场扩展规划设计（期货 + 隔夜外盘/港美股）

> 日期：2026-09-03 ｜ 状态：**M1/M2/M3/M4 已全部交付**（生产 8765 已加载，A股第 14 tab「联动观察」在线）
> 范围：仅规划「市场入口切换」与「数据指标 tab」两大设计；不含持仓/交易功能扩展。
> 关联：拍板后归档 Obsidian `05-决策记录ADR/`；实施遵守工程铁律（改前 .bak、py_compile / node --check、Playwright 复核）。

## 0. 一句话结论（推荐方案）

**不推翻现有 A 股 13-tab 工作流，在侧栏顶部加一组「市场切换 segment」（A股 / 港股 / 美股隔夜 / 期货 / 外盘商品），切换后内容区整体换为对应市场的专属 tab 集（概览→榜单→联动→自选），数据层以「统一行情网关 + 分市场抓取线程」承载。**

理由：A股工作台是「个人交易工作流」（时段建议/持仓/复盘），期货与港美股本质是**行情参考面**（尤其"隔夜外盘→今日A股"的联动判断），二者应作为独立视图存在，而非把 13 tab 撑成 40 tab。

## 2. 设计原则（从你的历史偏好推导，硬约束）

1. **不做常驻顶部横幅**（你已两次把顶部横条挪进左侧导航）→ 市场切换做进**侧栏**。
2. **红涨绿跌全局统一**（含美股视图，避免切换市场时颜色心智反转；美股传统绿涨只在文档注释中说明）。
3. **行情视图 = 参考，不碰持仓/下单语义**：港股/美股/期货页不含"买入建议"，只做观察 + 联动提示。
4. **tab 内容撑满容器宽度、视口自适应**（沿用现有 grid `minmax(0,1fr)` 模式）。
5. **新鲜度透明**：每个市场状态条必须显示「本地时钟 + 市场状态 + 数据源最后更新时间」（免费源有延迟，美股 ~15min 级，必须明示，防误读为实时）。
6. 只读参考面出现任何 FAIL 不阻塞 A股主流程（分市场错误隔离）。

## 3. 总体架构：两级导航模型

```
┌─────────────────────────────────────────────────────────┐
│ 工作台（单页，URL hash 记忆 #mk=hk / #mk=us / …）           │
│  ┌─ 侧栏(190px) ─┐  ┌──── 内容区 ────────────────────┐    │
│  │ 品牌行          │  │                                │    │
│  │ [市场切换 segment]│  │  wb-section 集（随市场切换注入）   │    │
│  │   A股│港股│美股  │  │                                │    │
│  │   隔夜│期货│外盘  │  │  每市场 = MarketShell(状态条)     │    │
│  │ ────────────── │  │  + 指标 tab(概览/榜单/联动/自选)   │    │
│  │ 业务 nav（随市场 │  │                                │    │
│  │ 过滤/替换）      │  │                                │    │
│  └────────────────┘  └────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
       市场维度=第1层（切换整页语境）   功能tab=第2层（市场内指标）
```

- **A股** = 现状 13 tab 原样（市场 segment 里 A股 激活时不做任何 DOM 变动，保证零回归）。
- **港股/美股隔夜/期货/外盘** = 注入各自 `.wb-section` 集（隐藏全部 A股 section，显示市场 section）。
- 记忆：`localStorage['wb-market']` + hash `#mk=`，刷新/手机重连保持上次市场。

## 4. 核心设计 A：市场入口切换（板块入口）

### A1. 控件形态（推荐）
侧栏 `brand-mini` 下加横向 segment（5 键一行，超窄屏换两行）：
`A股 · 港股 · 美股隔夜 · 期货 · 外盘`，激活键高亮（#0969da 底/白字或描边 pill），旁挂小状态点（● 交易中绿 / ○ 休市灰，取该市场实时状态）。

备选（不推荐）：内容区顶部 tab 条 —— 与你「禁止常驻顶部」偏好冲突；多市场 tag 用一行 segment 最省高度（<40px）。

### A2. 切换逻辑（改 `switchSection` 上游）
新 `switchMarket(mk)`：
1. 写 hash + localStorage；
2. `.wb-market-seg` 高亮切换；
3. A股：隐藏其他市场 section、显示 13 A股 section 并恢复上次 section；非 A股：隐藏 A股 section，显示 `[data-mk=hk|us|fut|glob]` 的市场 section 集；
4. 触发该市场 load（首开才拉，懒加载同现状）。

DOM 约定：非 A股 section 加双属性 `<section class="wb-section mk-panel" data-mk="hk" data-mksec="overview">`，市场内部 tab 复用 `switchMarketSection()`（机制同现状 section 切换，零新范式）。

### A3. 业务 nav 的跨市场语义（重要边界）
- 「持仓管理/时段建议/当日复盘/操盘心法/题材套利」= **A股专属工作流** → 仅 A股市场下列出；
- 「大盘速览/板块涨幅/个股异动/龙头候选/涨停池/风险池/自选」= **行情族** → 在港股/美股下换成对应市场的同名异构 tab（见 B2 矩阵）；
- 新增 **「联动观察」tab（A股↔外盘）** 仅在 A股市场下出现（给你开盘前用），它引用的正是隔夜面板数据——这就是本次扩展的**主价值链**。

## 5. 核心设计 B：数据指标 tab 设计

### B1. 每市场统一外壳（MarketShell）
```
┌ panel ───────────────────────────────────────────┐
│ ⏱ 本地 10:56:47 │ ●港股交易中 10:43 │ 源: 腾讯qt · 最后更新 10:43:14 │ 时区提示: 港股与A股重叠 09:30-11:30 │
└──────────────────────────────────────────────────┘
```
- 扩展 `market_status()` → `market_status(mk)`，内置每市场交易时段表（含美股夏令时、期货夜盘），返回 状态/颜色/下一关键时间（开盘/收盘倒计时）。
- 免费源延迟必须标注：美股 qt 数据 = 交易所收盘时刻（非实时 tick），加 `~15min` 灰标。

### B2. 指标 tab 三族 + 分市场矩阵

| 市场 | 概览族（指数卡条） | 榜单族（表格） | 联动族（本市场特色） | 自选族 |
|---|---|---|---|---|
| A股（现状不回归） | 6 指数卡 | 板块/异动/涨停池… | **新增「联动观察」**：隔夜外盘摘要条 | 自选·DK点 |
| 港股 | 恒指/国企/科技(HSTECH)/红筹 + 南向净流入 | 港股行业涨幅 / 涨幅榜 / 成交额榜 / 创新高 | A股↔港股：AH 溢价率排序、南向资金 | 港股自选(hk*) |
| 美股隔夜 | 道指/纳指/标普/费半/纳指100 + 美债10Y | 涨幅榜 / 中概股榜 / 热门科技 | 映射A股：NVDA→算力/CPO 链等（题材库复用） | 美股自选(us*) |
| 国内期货 | 股指(IF/IH/IC/IM) + 商品指数 | 主力涨幅榜 / 各板块(黑色/有色/能化/农产品/贵金属) | 夜盘隔夜→次日A股板块联动 | 期货自选(主连) |
| 外盘商品 | 黄金/白银/原油/铜/铝 + 美元指数 | 各品种涨跌 + 时点标注 | 与国内期货比价(内外盘差/溢价) | — |

### B3. 「联动观察」tab（核心增值，A股开盘前 09:00-09:25 重点看）
一个聚合面板，三行区块：
1. **隔夜外盘影响链**：美股科技 → 映射 A股题材（NVDA/CPO/铜缆、TSLA/锂电、苹果/果链…映射表扩自 `theme_library.json` 或新 `data/map_overseas_a.json`）；
2. **夜盘期货 → 今日板块**：铁矿/螺纹→钢铁、原油→油服化工、金铜→有色，红/绿箭头提示高开低开预期；
3. **港股已开盘快照**：A股 09:15 前港股已跑 45min，南向/腾讯/中概半日表现可作开盘情绪温度。

### B4. 自选跨市场扩展
`watchlist.json` 元素加 `type: "sh|sz|hk|us|fut"`；报价统一走 `_qt_symbol()` 的泛化版 `mk_symbol(code,type)`（hk00700 / usNVDA / nf_IF0 各源前缀），同一张「自选」面板按市场分组渲染（现状接口加参数或新端点）。

## 6. 数据层与后端设计

### 6.1 数据源实测矩阵（2026-09-03 实证，非推断）

| 需求 | 通道 | 实测 | 备注 |
|---|---|---|---|
| 港股指数/个股 | 腾讯 qt `q=hkHSI,hk00700` | ✅ 10:43 实时可用 | 与 A股同网关，代码零新增依赖 |
| 美股指数/个股 | 腾讯 qt `q=usDJI,usNVDA` | ✅ 返回美东收盘/近实时 | AAPL 等需验证 `.OQ/.N` 后缀规范 |
| 国内期货主连 | 新浪 `nf_IF0` | ✅ IF 股指主连完整字段 | 商品主连同族（nf_RB0 等）需 M3 批量校准 |
| 外盘贵金属/商品 | 新浪 `hf_GC` | ✅ 纽约黄金 4464.9 实时 | hf_CL(原油)/hf_SI(银) 同族；外汇可 hf_ 族或另选 |
| 期货全主连/兜底 | akshare `futures_main_sina()` | 未跑（二次核实） | 提供全主连清单+行情，避免手写代码表 |

> 沙箱代理注意：抓取线程启动前照 data_fetcher.py L11-16 清代理环境变量；新增源（新浪）需带 `Referer: finance.sina.com.cn`（实测必须）。

### 6.2 模块划分（推荐）

```
data_fetcher.py        —— 不动，仅将 _qt_symbol/quote_stocks 前缀化并复用
overseas_fetcher.py    —— 新增：OverseasData 类（港/美/外盘商品），独立线程组 + 内存缓存
futures_fetcher.py     —— 新增：FuturesData（新浪主连 + akshare 兜底），独立线程
config.py              —— 增加 MARKET_CONFIG：各市场指数清单/间隔/交易时段(含夏令时表)
app.py                 —— 新增端点：
                        GET /api/global?mk=hk|us      → 港/美聚合（指数+榜单+自选报价）
                        GET /api/futures              → 期货聚合
                        GET /api/linkage              → 联动观察（映射表计算）
```
刷新节律（独立线程各自 sleep，互不拖累）：港股 5s / 美股 30s / 期货 5s / 外盘商品 30s；A股现状不变。

### 6.3 交易时段状态表（状态机数据源，M1 内实现）

| 市场 | 时段（北京时间） | 状态粒度 |
|---|---|---|
| A股 | 09:15-11:30 / 13:00-15:00 | 现有 5 态 |
| 港股 | 09:00-09:30 竞价 / 09:30-12:00 / 13:00-16:00 | trading/lunch/closed |
| 美股 | 夏令 21:30-04:00 / 冬令 22:30-05:00（次日） | pre/trading/closed（按日期+夏令时表算） |
| 国内期货 | 日盘 09:00-10:15/10:30-11:30/13:30-15:00 + 各品种夜盘 21:00-次日 01:00~02:30 | 简单化：日盘/夜盘/休市 |
| 外盘商品 | 近 23h 连续（贵金属/原油分段） | 简化：交易/休市（GMT 换算） |

时钟以本机 NTP 为准；所有"倒计时/状态"服务端生成（后端 time），前端只渲染，避免手机端时区坑。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 美股免费源非 tick（~15min 级）被误读为实时 | 状态条灰标延迟；概览标注"交易所收盘时刻" |
| 新浪/腾讯免费源限流或封禁（曾发生 WAF 封 sina 全A） | 多源降级链（qt→新浪→akshare）、错误隔离不阻塞 A股 |
| 市场条/新 tab 把 A股页改出回归 | M1 起 A股路径不改 DOM 结构；每期必回归截图 |
| 文件越写越大（workbench 2405 行→将超 3000） | 市场面板为独立 `<template>` 片段/独立 mk-html 由后端注入，控制主文件膨胀 |
| 夏令时/时区算错导致状态错 | 时段表集中 config；用 UTC 偏移计算；验收含夏令时样例 |
| 手机端宽度 | segment 窄屏折行；表格沿用现状横向滚动/自适应 |
