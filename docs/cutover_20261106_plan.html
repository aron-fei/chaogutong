六、「按新的建议来做」的联动

切割的目的不是腾空间，是让新策略的历史序列从今天干净起步，不被老口径污染。确认切割后建议同步落地上一份调研报告里的 P1 项：

  • 题材强度历史落盘：新建 data/theme_strength_history.jsonl，每 30 分钟追加一行 {asof, schema_version:2, trends[...] }，只记录 cutover 之后的数据 → 支撑「连续 3 日区间强度 / 区间净额」，过滤一日游题材。
  • 涨停天梯 / 晋级率：复用涨停池 + 昨日涨停基线（84 只）算一板/二板/三板家数与晋级率，不需要历史积累，纯现算。
  • 老候选池降位：M8「底部放量」是老口径，L1 低位挖掘（趋势题材内、未涨停、量能刚抬头）接替主推荐位；老结果不再参与新评分。

这三项属于策略改动，在你确认切割方案前不做；确认后与切割同批交付并跑全量回归。
